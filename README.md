# Super-Market-Sales-Prediction

## Overview

An end-to-end AutoML regression platform built with **Streamlit** and **FLAML**.

## Tech Stack

- Python (requirements.txt based)
- Docker

## Getting Started

### Prerequisites

- Git
- Runtime dependencies for this project's stack

### Installation

```bash
uv venv
uv pip install -r requirements.txt
```

## Usage

Run the primary app with `uv run app.py`.

## Testing

Run tests with `uv run pytest` from repository root.
